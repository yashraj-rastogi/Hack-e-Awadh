# FinBuddy — UI/UX Guidelines

> **STATUS: DEFERRED / REFERENCE-DRIVEN**

Detailed UI/UX implementation rules are intentionally kept out of the product-development baseline until the supplied Paytm-themed design reference is frozen into a final implementation system.

The attached reference establishes the intended direction:
- Paytm-inspired trust, speed and financial-security feel,
- familiar consumer/Paytm-for-Business patterns,
- clean high-contrast layouts,
- strong transaction values and CTAs,
- audio-visual feedback inspired by the Soundbox experience,
- Paytm dark blue `#002E6E`,
- Paytm light blue `#00BAF2`,
- success green `#21C17A`,
- alert/error red `#FD5C63`,
- offer/growth yellow `#FFA800`,
- canvas `#F5F7FA`,
- white cards,
- Inter/Roboto-type readable sans-serif hierarchy,
- rounded Paytm-style components,
- customer scanner/cart/payment patterns,
- merchant dashboard + voice-first Copilot,
- equalizer/audio feedback for Copilot responses.

These source-derived visual rules should be converted into final screen-by-screen implementation guidelines after the team freezes the exact visual components. The product scope, screens, flows and architecture do not depend on this file being finalized.
